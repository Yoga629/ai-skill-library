# Contributing

Thank you for improving this AI skill library.

## Add or update a skill

1. Create or update one focused skill at `skills/<skill-name>/SKILL.md`.
2. Follow `SKILL_TEMPLATE.md`.
3. Use a short, lowercase, hyphen-separated folder name.
4. Update `SKILLS.md`.
5. Check that instructions are clear, testable, and not unnecessarily repetitive.

## Skill quality standards

A good skill should:

- Have one clear purpose.
- State its activation conditions and exclusions.
- Give an ordered workflow.
- Define expected output and quality checks.
- Identify assumptions, uncertainty, and safety boundaries.
- Avoid claiming that the AI has tools, access, or memory it may not have.

## Review checklist

- [ ] Markdown headings and links are valid.
- [ ] Instructions do not conflict internally.
- [ ] Examples demonstrate intended behavior.
- [ ] External references are relevant and accessible.
- [ ] No credentials, tokens, or private user data are included.
